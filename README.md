🏢 Smart Campus Tracker (by Team Nexus)
An enterprise-grade, multi-tier digital grievance and campus management system designed to bring transparency, accountability, and safety to educational institutions.

🚀 Overview
Smart Campus Tracker revolutionizes how campus infrastructure issues and emergencies are handled. Instead of relying on manual follow-ups, this system introduces an Automated SLA (Service Level Agreement) Escalation workflow. If the campus administration fails to resolve a critical issue within the stipulated time, the ticket automatically escalates to the Management Executive tier, ultimately holding the system accountable through automated student penalty vouchers.

🎯 Hackathon Theme Alignments
GovTech & CyberTrust (Theme 16): Acts as a transparent digital grievance system ensuring accountability at every administrative level.

Tech4Her & Campus Safety (Theme 5): Features a dedicated Emergency SOS panic button for immediate administrative and security alerts.

ConnectTech (Theme 17): Seamlessly bridges the communication gap between Students, Admin, and Top Management.

✨ Key Features
⏳ 3-Tier Automated SLA Escalation: Issues flow from Admin ➡️ Management ➡️ Student Penalty if deadlines are breached.

🚨 Emergency SOS Panic Button: Instantly captures user location and broadcasts an active SOS alert to campus security.

🪄 Smart QR Auto-Fill: Scan physical QR codes placed on campus rooms to auto-fill location data in the reporting form.

🎙️ Voice-to-Text Reporting: Built-in speech recognition for accessibility and fast issue description.

🔔 Real-Time Sync & Notifications: Instant dashboard updates and browser notifications via Firebase Firestore.

💻 Tech Stack
Frontend: HTML5, Tailwind CSS, JavaScript (ES6+)

Backend & Database: Firebase Firestore (NoSQL Cloud Database)

APIs & Tools: Web Speech API, Geolocation API, FontAwesome, QR Code Generator
