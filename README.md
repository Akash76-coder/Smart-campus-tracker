# Smart-campus-tracker
"Smart Campus Tracker by Team Nexus is an automated SLA grievance portal ensuring campus accountability. It features 3-tier escalation (Admin ➡️ Management ➡️ Student Penalty), QR auto-fill, voice reporting, and emergency SOS alerts. Built with Firebase &amp; Tailwind CSS, it aligns with GovTech, ConnectTech, and Campus Safety frameworks."
